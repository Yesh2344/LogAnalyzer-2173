## Overview

Log Analyzer is a modern React application that fetches, parses, and visualizes server logs. It provides:

- Real‑time fetching with error handling
- Search & filter capabilities
- Pagination for large data sets
- Extensible architecture using hooks, context, and utility modules
- Comprehensive unit tests with React Testing Library
